Ask a question

An agent on Databricks Model Serving chooses which tools to call (document search, the survival-model forecast, project records, early warnings). Every sentence of its answer is then checked: it must cite a source a tool returned, its numbers must be in that source, the country must match, and a separate judge model must agree the source supports it. Sentences that fail are removed and shown below with the reason.

Follow-up questions use the earlier answers in this conversation.
