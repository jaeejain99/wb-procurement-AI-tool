               The World Bank                                                                         Implementation Status & Results Report

               Ghana Climate Innovation Center (P145765)







 Project implementation had experienced considerable delays in 2016 as the lack of a core team in place to manage the GCIC, including an Executive

 Director to provide leadership to the project implementation, held up overall implementation progress. A set of actions was agreed in December 2016

 between the World Bank and the GCIC consortium to improve project implementation. These actions covered the following areas: (i) Executive Director

 and Core Staff Recruitment, (ii) Work Program Planning, (iii) Launch of Programs, (iv) Advisory Board Setup, (v) WBG Supervision Strengthening, (vi)

 Technical Support, and (vii) Project Reporting.

 The project team was pleased to confirm that these actions have all been advanced as agreed and implementation issues have now been addressed by

 the project implementation partners. Notably, a GCIC Executive Director has been recruited and is supported by a core team of GCIC staff as well as

 the combined resources of Ashesi University and the GCIC consortium partners.

 A first cohort of client entrepreneurs and SMEs has been recruited and a first round of advisory work has taken place on site for each of the

 entrepreneurs. The full range of GCIC support programs for entrepreneurs including advisory, financing, technology support and market development

 work is being launched in May of 2017. Additionally, a new implementing agency for component 2 (the early stage climate venture financing facility) has

 been identified through a competitive selection, thereby freeing up Ashesi University and its consortium partners to concentrate on continued effective

 implementation of the GCIC.

 Project development objectives are still achievable within the project timeline if implementation going forward maintains the efficiency and effectiveness

 shown during CY 2017 (since the last ISR was completed and the set of actions was agreed in December 2016). The World Bank project task team will

 continue to closely monitor implementation progress to ensure this progress and efficient implementation is maintained throughout the project

 implementation period.
