 1.1 Development Objective
   Original Development Objective (Approved as part of Approval package on 19-Dec-2024)
   The Project Development Objectives (PDOs) are to (i) increase access to safely managed water supply in Chattogram; and
   (ii) improve operational performance and financial sustainability of Chattogram Water Supply and Sewerage Authority
   (CWASA).

4. KEY ISSUES & STATUS


4.1 Implementation Status and Key Decisions
  The project received Board approval on December 19, 2024. The financing agreement was signed on May 10, 2025, and
  the project became effective on August 8, 2025. Recruitment of essential PMU staff and consultants is underway. Key
  start-up activities have commenced, and procurement processes for various key consultancy services have been initiated
  including the one for Design Review and Construction Supervision. The preparation of the bid package for the
  implementation of the District Metered Areas (DMAs) is underway and CWASA is finalizing the procurement document.
  The project implementing entity i.e. Chattogram Water Supply and Sewerage Authority (CWASA) is required to establish
  the full project management arrangements at CWASA and implement the key project start-up activities especially the key
  technical assistance activities that will govern the investment activities during the project implementation period. It is
  critical to have key staff on board soon to fully launch project implementation activities.



4.2 MPA Program Development Objective
  Original MPA Program Development Objective (Approved as part of (Seq. ) package on )


  Current MPA Program Development Objective (Approved as part of (Seq. ) package on )




4.3 Multiphase Programmatic Approach (MPA) Status (Public Disclosure)
  The first phase of the MPA, the Chattogram Water Supply Improvement Project (CWSIP) is on track for Board approval in
  Q2 FY25.
  The second phase of the MPA, the Metro Dhaka Water Security and Resilience Program is under preparation. The
  Program Concept Note review is scheduled on December 4, 2024. The Program will support all the key cities in the Metro
  Dhaka region for improving access to safely-managed WSS services, reducing water pollution, and enhancing flood
  resilience.
  The preparation for the third and the fourth phase of the MPA is yet to start formally, though GOB is advancing the
  preparatory activities with the task team's assistance.
