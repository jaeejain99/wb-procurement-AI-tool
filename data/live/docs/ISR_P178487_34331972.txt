1. PROJECT DEVELOPMENT OBJECTIVE


 1.1 Development Objective
   Original Development Objective (Approved as part of Approval package on 21-Sept-2023)
   The Program Development Objective (PDO) is to improve student learning and retention, and build system resilience in
   secondary education.

3. KEY ISSUES & STATUS


 3.1 Implementation Status and Key Decisions
   The first Implementation Support Mission (ISM) for Learning Acceleration in Secondary Education (LAISE) Operation was
   held from May 12-19, 2024. The mission found that, despite being in its initial stage, the Program has made a great start,
   with the Directorate of Secondary and Higher Education (DSHE) making significant progress in establishing the agreed-
   upon institutional set-up, laying the groundwork for effective implementation

   The Program was declared effective on November 30, 2023. The government has successfully appointed a full time
   Project Director and completed authorization of signatory for the project. Project Implementation Unit (PIU) deployment
   of staff has also been completed. The establishment of the Program Steering Committee, Program Implementation
   Committee, and Program Implementation Unit have been completed through approval of the Development Project
   Proforma (DPP).
